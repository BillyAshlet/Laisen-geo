# Laisen-geo｜城市空间规划情景模拟

> 以真实地理数据为参照、以俯视专题图为界面的交互式城市规划教学原型。通过调整街区与设施布局，观察城市热环境、雨洪响应、交通通勤等指标的变化，理解有限空间资源下的多目标权衡（trade-off）。

[在线体验](https://laisen.vercel.app) · [项目设计简报](./BRIEF.md) · [GitHub 仓库](https://github.com/BillyAshlet/Laisen-geo)

> **开发状态：原型迭代中。** 本项目用于地理教学和情景探索，不是城市规划审批工具，也不提供可直接用于工程设计的温度、积水深度或交通预测。

## 项目目标

城市建设的效果并非只由“修了多少设施”决定，也与**设施建在哪里、占用了什么土地、周围是什么地形和路网**密切相关。本项目将自然地理本底、城市空间布局、简化机制模型和可视化反馈连接起来，让使用者在同一幅城市俯视图中提出规划方案、观察空间响应并比较其代价。

```text
自然地理本底（地形／水系／地表覆盖／道路）
                  ↓
规划操作（街区绿地率、开发强度、设施选址、降雨情景）
                  ↓
空间机制计算（热环境／雨洪汇流／通勤可达性）
                  ↓
专题地图 + 指标面板 + 方案对比
                  ↓
规则型 Agent：感知现状 → 评估候选操作 → 提出建议
```

项目**借鉴 GIS 的空间数据组织与专题制图方式**，但不是 ArcGIS/QGIS 插件；当前 Web 原型无需接入大语言模型 API。

## 当前功能

| 模块 | 当前实现 |
| --- | --- |
| 双模式 | **长春模式**：以真实地理空间数据作为参照；**沙盒模式**：使用简化地形与路网探索机制 |
| 城市俯视图 | 2D 地图呈现道路、街区、绿地、水系等空间要素 |
| 街区调整 | 对可编辑街区调节**绿地率**、**开发强度**；自然或历史本底存在编辑限制 |
| 设施选址 | 放置或移除**工厂、公园、湿地/调蓄池、交通站点**，并按选址条件判断能否建设 |
| 情景设定 | 切换不同降雨情景，查看模拟雨洪响应 |
| 多视图反馈 | 联动显示**地表温度、内涝、通勤、人口分布**等专题图及城市指标 |
| 规则型 Agent | 对可行的街区调整和设施方案进行试算、比较和解释，输出建议；**不调用大模型** |
| 方案比较 | 展示调整前后的指标差异与空间变化；长春模式可辅助对照真实地理数据 |
| 双语界面 | 提供中文和英文界面切换 |

这里的“实时”指浏览器在用户操作后重新计算并刷新**模拟结果**，不代表实时采集城市传感器数据。

## 关键指标与机制

| 指标 | 模型思路 | 科学边界 |
| --- | --- | --- |
| 地表温度（LST） | 利用地表覆盖、不透水率、开发强度、绿地及邻域条件估算相对热环境响应 | 当前显示值包含演示性映射系数，不能等同于实测气温或经独立验证的绝对地表温度 |
| 相对内涝易发性 | 基于高程数据、D8 流向、径流系数、蓄滞能力与简化排水阈值进行空间计算 | 不等于经过水动力模型验证的积水深度、淹没范围或灾害损失 |
| 交通可达性／通勤 | 在街区路网图上计算出行时间，并用岗位分布与距离衰减构建通勤／可达性指标 | 不等于真实交通流量预测，尚未完整考虑拥堵反馈、出行行为与道路容量 |
| 人口与产业表现 | 按街区类型、开发强度和设施配置估计人口、岗位及简化制造产出 | 用于教学约束与权衡，不是人口普查或经济统计预测 |

项目关注**空间位置、约束与联动机制**：一片新增绿地可能缓解局部热环境，也会占用有限的建设空间；新设施可能改变通勤、用地及环境响应。不同目标并不被预先规定为“必定冲突”，其变化取决于情景与模型假设。

## 地理数据

当前长春模式使用预处理后的 **200 m 网格数据**（见 `app/data/changchun.js`）。主要来源包括：

| 数据 | 来源 | 用途 |
| --- | --- | --- |
| 土地覆盖（2021） | ESA WorldCover | 地表覆盖类型与空间本底 |
| 地表温度（2023） | 团队已有长春 LST 数据成果 | 地表热环境参照与对比 |
| 高程 | Copernicus GLO-30 | 地形、汇流与选址约束 |
| 道路 | OpenStreetMap（OSM） | 道路结构与街区划分 |
| 研究区边界 | 团队整理的长春四环范围边界 | 统一裁剪和空间对齐 |

其中 GLO-30 为**数字表面模型（DSM）**，可能包含建筑物和树冠的高度影响；它与适合精细水文模拟的裸地 DEM 不完全相同。不同数据的采集年份、分辨率和适用条件也不一致。

数据经统一网格处理后用于教学模拟。关于原始栅格、道路矢量、来源记录、校验脚本及具体处理方法，参见 [长春四环 200 m 基础数据 PR #1](https://github.com/BillyAshlet/Laisen-geo/pull/1)。相关原始数据文件是否已进入默认分支，请以该 PR 的实际合并状态为准。

> **研究与复现提醒：** 情景模型中的经验参数包含为原型演示而设的简化假设。若用于论文、实证研究或真实规划评价，应补齐 LST 影像日期及质量控制、参数出处、敏感性分析和独立验证；随机森林／SHAP 的相关性或特征贡献不能直接视作规划干预的因果效应。

## 本地运行

前端为 HTML、CSS 和原生 JavaScript，可用静态 HTTP 服务启动；**运行已有网页不需要 Node.js、第三方 Python 依赖或大模型 API**。

```bash
git clone https://github.com/BillyAshlet/Laisen-geo.git
cd Laisen-geo
python -m http.server 8000
```

在浏览器打开：**http://localhost:8000/app/**

也可使用其他静态文件服务器，将网站根目录指向仓库中的 `app/`。建议使用现代桌面浏览器以获得更稳定的 Canvas 交互体验。

### 可选：重新生成长春网页数据

仅在持有对应原始数据包时需要执行。先安装脚本所需的 Python 依赖：

```bash
python -m pip install numpy tifffile
python -X utf8 scripts/build_changchun_grid.py <数据包目录> app/data/changchun.js
```

数据包需要包含同网格的三张 GeoTIFF，以及配套道路 GeoJSON。该命令会**覆盖**目标 JS 文件，请在新分支上执行并核查输出。详细文件结构与校验说明参见上方 PR #1。
